# Alura Store — Análise de Vendas
## Descrição do Projeto

Este projeto foi desenvolvido no **Google Colab** como parte do **Desafio Alura Store**, da Especialização em **Data Science**.  A ideia do projeto é analisar o desempenho de quatro lojas de um e-commerce e apoiar uma decisão estratégica de negócio baseada em dados.

A partir da análise, foi possível identificar **qual loja apresenta o pior desempenho geral** e, portanto, é a mais indicada para ser vendida.

---

## Objetivo

Avaliar o desempenho das lojas da Alura Store e recomendar ao Sr. João **qual loja deve ser vendida**, utilizando métricas de vendas, avaliação de clientes e custos operacionais.

---

## Base de Dados

Os dados utilizados são arquivos CSV fornecidos pela Alura, contendo informações como:

- Produto  
- Categoria do Produto  
- Preço  
- Frete  
- Avaliação da compra  

Os dados foram carregados diretamente no notebook via URLs oficiais do repositório do desafio.

---

## Métricas Analisadas

- Faturamento total por loja  
- Categorias mais vendidas  
- Produtos mais e menos vendidos  
- Média de avaliação dos clientes  
- Custo médio de frete por loja  

Essas métricas permitiram uma análise completa do desempenho comercial e operacional de cada loja.

---

## Visualizações

O projeto inclui gráficos criados com **Matplotlib** e **Seaborn**, como:

- Gráficos de barras (verticais e horizontais)
- Gráfico de pizza
- Comparações entre lojas e categorias

As visualizações facilitam a interpretação dos dados e apoiam a tomada de decisão.

---

## Conclusão

Após a análise conjunta de todas as métricas, conclui-se que:

> **A Loja 4 apresenta o menor desempenho geral e é a mais indicada para ser vendida.**

### Principais pontos:
- Menor faturamento total
- Menor destaque entre produtos e categorias mais vendidos
- Avaliações que não compensam o baixo volume de vendas
- Menor competitividade em relação às Lojas 1, 2 e 3

As **Lojas 1, 2 e 3** demonstram melhor desempenho e maior estabilidade, sendo recomendadas para manutenção.
